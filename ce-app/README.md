# 🎬 Cutting Edge (CE)

**Clip smarter, not harder.**

AI-powered video clipping studio — open-source Windows desktop app.

## 📁 ساختار

```
ce-app/
├── backend/     # FastAPI + SQLite + Pipeline
├── frontend/    # React + Electron + Auto-Update
├── scripts/     # Windows build scripts
└── .github/     # GitHub Actions workflow
```

## 🚀 Build

به تب **Actions** بروید → **🎬 Build Cutting Edge** → **Run workflow
